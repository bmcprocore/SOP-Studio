Section 01 · Overview

Purpose, scope and roles

This SOP defines how Citiport Holdings runs estimating-to-tender using Bestimating — Procore's bi-directional integration between the Estimating and Bidding tools. It replaces re-keying an estimate into a separate bid form: bid packages are generated directly from the estimate, and leveled bid responses flow back in with a single click.

Applies toPreconstruction & Estimating teams on active tender pursuits using Procore Bidding v2.0

Roles & responsibilities

Set up the estimate

Steps 1–6: from project creation through to a completed estimate ready to become a bid package.

Reference toolEstimating · Drawings · Documents
  1. 01

    Create the project

    EstimatorProcore · Portfolio~10 min

    Create the Citiport Holdings project in Portfolio (or confirm you hold Read Only + "create new projects" privilege).

  2. 02

    Upload, review & publish drawings

    EstimatorProcore · Drawings~30 min

    Upload tender drawings, confirm sheet numbering/revisions, then publish so they are available for takeoff.

  3. 03

    Add models to Project Documents (if applicable)

    EstimatorProcore · Documents / Models~15 min

    For BIM-based takeoff, add the coordinated model to Project Documents before proceeding.

  4. 04

    Run takeoffs

    EstimatorProcore · EstimatingVaries

    Add 2D takeoffs from the published drawings, or 3D takeoffs from the model, to quantify scope.

  5. 05

    Add the estimate

    EstimatorProcore · EstimatingVaries

    Build the estimate from takeoff quantities, organised into groups that mirror how you intend to package the tender.

    Beta noteCost codes are not currently pulled into a bid form — confirm cost coding is reconciled manually after import.
  6. 06

    Create the bid package

    EstimatorProcore · Bidding~20 min

    Generate the bid package directly from the estimate. Each estimate creates one bid package; a separate bid form is created for each group within the estimate.

    ProcoreLine items default to Response Field Type: Amount. Only switch a line to unit quantity if the estimate itself is unit-based — otherwise imported bids will not match on import.

Section 02 · Procedure (2 of 2)

Solicit, level and award

Steps 7–12: invite bidders, run bid day, and bring the awarded pricing back into the estimate and Budget.

Reference toolBidding · Estimating · Budget
  1. 07

    View the bid form & invite bidders

    Bid ManagerProcore · Bidding~30 min

    Confirm the auto-generated bid form, add any supporting documents, then invite bidders from your Directory or the Procore Construction Network.

  2. 08

    Level bids

    Bid ManagerProcore · BiddingBid day

    As responses arrive, review and level submissions side by side. Estimate groups and line items show response status (responded / selected / included) to speed up comparison.

  3. 09

    Link leveled bid values to the estimate

    EstimatorProcore · Estimating~20 min

    Include/exclude selected bid response pricing to update the estimate. Multi-select line items to bulk-update several at once.

    Beta noteIf a bid form was switched to unit quantity but the bidder submitted on Amount, the units will not match and the import will error — have the bidder resubmit, or alter the bid in Bidding before importing.
  4. 10

    Generate the bid proposal

    Bid ManagerProcore · Bidding~15 min

    Compile the updated estimate into the owner-facing proposal.

  5. 11

    Export the bid proposal

    Bid ManagerProcore · Bidding~10 min

    Export the proposal for internal review and, where required, owner submission.

  6. 12

    Send the estimate to Budget

    Project ManagerProcore · Budget~10 min

    Once awarded, send the final estimate to the project Budget to establish the baseline for Commitments.

Section 03 · Close out

Beta considerations, checks & approvals

Bestimating is in open beta — confirm the items below before relying on it for a live tender.

Owner[Process owner]

Beta considerations

  • You can create multiple bid packages from the project's Estimating tool; each estimate creates one bid package.
  • A separate bid form is created for each group within an estimate — structure estimate groups to match your intended packages before generating.
  • Cost codes are not currently pulled into a bid form; reconcile cost coding manually after import.
  • Editing a bid form to add sections can mismatch data — Unit/Qty items may roll up into a total amount on import back into Estimating.
  • Bid form line items default to Amount. Switching a line to unit quantity only syncs correctly if the estimate itself is unit-based; otherwise have the bidder resubmit on Amount, or alter the bid in Bidding before importing.
